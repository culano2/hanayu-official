# Codex Notes for HANAYU

Work in the existing project. Do not recreate the app or change the core stack.

## Keep

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS v4
- App Router
- Existing folder structure
- `app/globals.css`

## Working Rules

- Read existing components and data before editing.
- Keep architecture changes scoped and commercial-ready.
- Prefer Server Components unless interactivity is required.
- Use `"use client"` only for components with state, effects, or browser interaction.
- Move repeated content into `data/`.
- Use reusable primitives from `components/ui/`.
- Do not introduce unrelated dependencies.
- Do not significantly change visuals during architecture-only sprints.

## Verification

Run both checks before completion:

```bash
npm run lint
npm run build
```

On Windows, `npm.cmd` is acceptable when PowerShell execution policy blocks `npm`.
