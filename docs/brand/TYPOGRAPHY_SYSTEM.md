# HANAYU Typography System

## Hierarchy

| Level | Role | Guidance |
| --- | --- | --- |
| Hero | First-view brand signal | Large, letterspaced, calm, never crowded |
| Page Title | Major page identity | Strong hierarchy for future pages |
| Section Title | Story section heading | Editorial and readable across mobile |
| Body | Long-form brand copy | Comfortable line-height and restrained width |
| Caption | Eyebrows and metadata | Uppercase, letterspaced, used sparingly |

## Tone

Typography should feel precise and premium without becoming decorative. Chinese copy should avoid oversized mobile scaling; English brand marks can use wider tracking.

## Token Source

Use `tokens/typography.ts` as the implementation source of truth.
