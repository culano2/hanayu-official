# HANAYU Color System

## Official Colors

| Name | Hex | Usage |
| --- | --- | --- |
| Deep Ocean | `#031320` | Primary background, hero overlays, premium dark surfaces |
| Midnight Blue | `#0A2438` | Secondary dark surfaces and navigation glass |
| Ocean Slate | `#506474` | Body copy, secondary text, restrained UI details |
| Premium Gold | `#C89A4B` | Primary accents, focus states, premium CTA treatment |
| Pearl White | `#F7F6F3` | Light backgrounds and text on dark imagery |
| Mist Gray | `#D8DEE2` | Borders, quiet dividers, secondary light surfaces |

## Usage Rules

- Deep Ocean should remain the dominant brand anchor.
- Premium Gold should be used sparingly for emphasis and interaction.
- Pearl White should provide calm contrast instead of pure white whenever possible.
- Ocean Slate and Mist Gray should support hierarchy without making the interface feel cold.

## Token Source

Use `tokens/colors.ts` as the implementation source of truth.
